React Server Components change the API boundary

A compact technical article used to reproduce LiteTrace release screenshots.

React Server Components let teams move data fetching and rendering work closer to the server while keeping the client bundle smaller.

React 服务器组件让团队把数据获取和渲染工作放到更靠近服务器的位置，同时让客户端包更小。

The API boundary becomes easier to reason about when product code uses the same terminology across documentation, comments, and UI text.

当产品代码在文档、注释和界面文本中使用一致术语时，接口 边界会更容易理解。
